# Privacy

Live results remain in memory until the application closes. There is no telemetry or automatic persistence. Qt stores only language and redaction preferences in the user's standard application settings. The application does not collect hostname, IP address, usernames or file contents. Account checks count entries without listing names. The selected directory path is hidden in reports by default; turning redaction off explicitly can include it.

Published screenshots in this repository were captured from the real UI after a live local audit. They show OS version and aggregate findings only. Live report exports are never included in the repository; review before sharing one. The screenshot script performs another real audit and should be run only on a machine whose aggregate result may be shared.
