# Linux Security Auditor — руководство на русском

[Главный README](../README.md) · [O‘zbekcha](README_UZ.md) · [English](README_EN.md)

Linux Security Auditor выполняет ограниченную **локальную проверку только для чтения**. Подтверждённые результаты отделены от проверок, для которых данных недостаточно, и от неприменимых проверок. Начальная область проверки правил: Ubuntu 22.04/24.04 и Debian 12.

## Запуск

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Нажмите **Проверить компьютер**. Для проверки прав доступа выберите папку явно: программа читает только метаданные, пропускает символические ссылки и ограничивает обход. В **Результатах** показаны доказательства, источник, влияние, ограничения и рекомендации для ручной проверки. **Разделы** открывают отфильтрованные результаты. **Отчёты** создают локальные HTML, PDF и JSON. **Настройки** управляют скрытием пути в отчётах и описывают метод. Выбранный язык сохраняется после перезапуска.

## Как понимать результаты

`PASS` означает соответствие только конкретному правилу по доступным данным, а не полную безопасность компьютера. `WARN` и `FAIL` требуют проверки человеком. `UNKNOWN` означает недостаток данных. `NOT_APPLICABLE` означает, что проверка неприменима, например нет SSH-сервера. Рекомендации никогда не выполняются программой. [Правила](RULE_CATALOG.md) · [Метод](METHODOLOGY.md) · [Безопасность](SECURITY.md).

## Ограничения

Это не тест на проникновение, не сертификат CIS и не гарантия полной защиты. У обычного пользователя могут быть недоступны действующие правила брандмауэра. Кэш APT может устареть. Для проверки запустите `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` и `.venv/bin/python -m ruff check .`. [Тестирование](TESTING.md) · [Платформы](PLATFORMS.md).
